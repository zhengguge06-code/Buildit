# Vibe 产品分类口径 v3

## 定位

`Vibe 产品` 不再按“页面设计 / 交互体验 / 信息架构”这种参考维度做一级分类。

新的核心心智是：

- 先看这是什么类型的产品
- 再看它还值得借鉴哪里

对应关系：

- `Vibe 工具`：用什么做
- `Vibe 产品`：可以做成什么类型的产品，以及这些产品值得拆哪里

## 一级分类

当前 `Vibe 产品` 固定为 7 个产品类型：

1. `效率协作`
2. `内容创作`
3. `多媒体`
4. `学习教育`
5. `营销增长`
6. `商业金融`
7. `健康生活`

这些分类是主分类，不再混入“增长运营 / 商业转化 / 品牌表达”这类参考维度。

## 分类定义

### 1. 效率协作

面向任务管理、知识协作、会议记录、办公效率、团队沟通等产品。

典型样本：

- `Linear`
- `Notion`
- `Granola`
- `Discord`

### 2. 内容创作

面向创作者工作流、内容发布、创作分发、创作者商业化等产品。

典型样本：

- `Typefully`
- `Substack`
- `Kit`
- `beehiiv`

### 3. 多媒体

面向音视频、生成式媒体、声音、剪辑与创意表达等产品。

典型样本：

- `Descript`
- `Riverside`
- `Runway`
- `ElevenLabs`

### 4. 学习教育

面向学习、训练、知识教学和教育体验的产品。

当前先保留为空类目，作为后续扩展位。

### 5. 营销增长

面向分发、归因、转化、增长基础设施和营销协作等产品。

典型样本：

- `Dub`

### 6. 商业金融

面向商业管理、财务、账户、运营后台等产品。

典型样本：

- `Mercury`
- `Midday`

### 7. 健康生活

面向健康、生活方式、消费体验和长期习惯相关产品。

典型样本：

- `Oura`

## Badge 体系

主分类只回答“它是什么产品”，badge 再回答“它值得拆哪里”。

### Reference Badges

- `首页设计`
- `Onboarding`
- `定价设计`
- `结果页`
- `信息架构`
- `增长机制`
- `品牌表达`

### Capability Badges

- `多媒体`
- `AI Native`
- `社区`
- `协作`

### Platform Badges

- `Web`
- `移动端`
- `桌面端`

## 归类规则

### 单主分类

每个 `Vibe 产品` 只保留 1 个主分类。

### 多 badge

同一个产品允许同时挂多个 badge，用来表达它在页面、结构、增长、平台等维度上的参考价值。

### 优先级

如果一个产品同时覆盖多个方向，先确定它最核心的产品类型，再用 badge 补充其他价值。

## 当前结论

- 旧的 `页面设计 / 交互体验 / 信息架构` 已退出一级分类
- `增长运营 / 商业转化 / 品牌表达` 不再作为主分类存在
- `Vibe 产品` 先按产品类型浏览，再按 badge 补充参考点
